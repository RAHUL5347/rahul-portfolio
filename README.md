# S. Rahul – Portfolio

Personal portfolio website of **S. Rahul**, Junior AI Engineer at ParyAI Solutions (Python, RAG, LLM applications and industrial data pipelines).

Built with plain HTML, CSS and JavaScript. No build step or dependencies.

## Pages

| Page | File |
|---|---|
| Home (intro and about) | `index.html` |
| Experience | `experience.html` |
| Projects | `projects.html` |
| Skills | `skills.html` |
| Education | `education.html` |
| Contact | `contact.html` |

Shared files: `style.css` (styling, light and dark mode) and `script.js` (copy-to-clipboard buttons). The resume is `S.Rahul.pdf`.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy

Push to GitHub, then enable **Settings → Pages → Deploy from branch → `main` / root**.
